# Descripción del sistema
## Nombre
Sistema de Gestión de Citas y Atención Virtual 
## Problema
Una institución necesita administrar de manera centralizada la programación y seguimiento de citas de atención virtual.

Actualmente, la gestión de horarios disponibles, reservas, reprogramaciones y cancelaciones puede realizarse mediante diferentes medios, lo que puede ocasionar duplicidad de citas, pérdida de información y dificultades para conocer el estado de cada atención.

El sistema permitirá organizar los horarios de los profesionales, gestionar las reservas de los usuarios y realizar el seguimiento de las citas desde su programación hasta la finalización de la atención.

## Actores
- Usuarios o paciente.
- Prfesionales encargados de la atención
- Administrador del sistema.
## Canales
- Aplicación Web
- Acceso desde computadora, tablet o telefono móvil mediante navegador web.
## Procesos principales
- Registro de Usuario.
- Registro de Profesionales.
- Gestión de horarios disponibles.
- Consulta de Horarios.
- Reservas de citas.
- Reprogramación de citas.
- Seguimiento del estado de la cita.
- Atención virtual.
- Consulta del historial de citas.
## Objetivo del análisis
Definir los requerimientos funcionales y no funcionales necesarios para el desarrollo de un sistema de gestión de citas y atención virtual, y posteriormente realizar una validación inicial mediante un agente especializado en análisis de requerimientos.
