# Decisiones — Landing pública

## Sistema

Sistema de Gestión de Citas y Atención Virtual
del Hospital Boliviano Español.

## Decisiones aprobadas

- D-LAND-01: `07_landing` estará separado de `06_codigo`. APROBADO.

- D-LAND-02: la Landing será pública y estará orientada a presentar
  los servicios médicos del Hospital Boliviano Español. APROBADO.

- D-LAND-03: la Landing no incorporará autenticación,
  login, dashboard ni funciones administrativas. APROBADO.

- D-LAND-04: la Landing utilizará información real disponible
  en la base de datos del sistema. APROBADO.

- D-LAND-05: se podrán mostrar especialidades médicas
  y médicos activos registrados en el sistema. APROBADO.

- D-LAND-06: el acceso a datos desde la Landing será
  exclusivamente de solo lectura. APROBADO.

- D-LAND-07: en runtime solo se permitirán consultas SELECT.
  La Landing no podrá registrar, modificar ni eliminar
  información de la base de datos. APROBADO.

- D-LAND-08: tecnologías:
  PHP 8.x + PostgreSQL + PDO + HTML5 + CSS3 +
  JavaScript ES6+. APROBADO.

- D-LAND-09: la Landing será responsive y deberá funcionar
  correctamente en móvil, tablet y escritorio. APROBADO.

- D-LAND-10: la Landing deberá tener un CTA principal visible
  para orientar al usuario hacia la atención médica
  y la gestión de citas. APROBADO.

- D-LAND-11: no se implementará todavía una reserva de citas
  desde la Landing mientras no exista el Backend correspondiente.
  No se simularán funcionalidades inexistentes. APROBADO.

- D-LAND-12: las imágenes utilizadas deberán tener
  procedencia verificable y respetar la política de imágenes
  definida para el proyecto. APROBADO.

- D-LAND-13: se utilizarán los skills definidos
  en `.agents/skills-landing-manifest.json`
  en los checkpoints correspondientes. APROBADO.

- D-LAND-14: las auditorías visuales, de animación,
  accesibilidad y performance serán obligatorias
  antes del cierre. APROBADO.

- D-LAND-15: human-in-the-loop obligatorio.
  Ningún checkpoint será aprobado automáticamente.
  La decisión final pertenece al estudiante. APROBADO.
