# Alcance

## Incluye

- Registro y gestión de pacientes.
- Registro y gestión de médicos.
- Gestión de especialidades médicas.
- Definición de horarios disponibles por médico.
- Consulta de médicos y especialidades disponibles.
- Consulta de horarios disponibles para atención.
- Reserva de citas médicas.
- Reprogramación de citas.
- Cancelación de citas.
- Gestión del estado de las citas.
- Consulta de citas programadas por parte del paciente.
- Consulta de la agenda de citas por parte del médico.
- Gestión de citas por parte del personal de admisión o recepción.
- Registro de la finalización de una atención.
- Consulta del historial de citas del paciente.
- Gestión básica de roles de paciente, médico, personal de admisión y administrador.
- Gestión de citas destinadas a atención virtual cuando corresponda.
- Acceso a la información necesaria para ingresar a una atención virtual.

## Fuera de alcance

- Gestión de historias clínicas.
- Registro de diagnósticos médicos.
- Prescripción de medicamentos.
- Gestión de farmacia.
- Gestión de laboratorio.
- Gestión de internaciones.
- Gestión de emergencias.
- Facturación y cobro de servicios médicos.
- Gestión de seguros médicos.
- Gestión contable del hospital.
- Desarrollo de una plataforma propia de videollamadas.
- Uso de inteligencia artificial para diagnóstico médico.
- Gestión de estudios médicos o resultados de laboratorio.

## Integraciones actuales

En la primera versión del sistema no se consideran integraciones obligatorias con otros sistemas hospitalarios o servicios externos.

## Integraciones futuras

- Servicios externos de videollamada para atención virtual.
- Servicios de correo electrónico para confirmación y recordatorio de citas.
- Servicios de mensajería para notificaciones.
- Sistemas de historia clínica electrónica.
- Sistemas hospitalarios existentes.
- Calendarios externos para sincronización de citas.
