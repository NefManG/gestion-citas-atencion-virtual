# Descripción del sistema

## Nombre

Sistema Web de Gestión de Citas y Atención Virtual para el Hospital Boliviano Español.

## Problema

Para efectos del presente proyecto se plantea la necesidad de contar con un sistema
que permita centralizar la gestión de citas médicas del Hospital Boliviano Español.

La administración de citas requiere controlar la disponibilidad de los médicos,
las especialidades, los horarios de atención, las reservas realizadas por los
pacientes, las reprogramaciones, las cancelaciones y el estado de cada cita.

Cuando esta información se gestiona mediante diferentes medios, puede resultar
más difícil mantener un control centralizado de los horarios disponibles y realizar
el seguimiento de las citas programadas.

Por este motivo, se propone desarrollar un sistema web que permita organizar y
centralizar la gestión de citas médicas, facilitando a los pacientes la consulta
de disponibilidad y la reserva de citas, y permitiendo al personal autorizado
administrar los horarios y realizar el seguimiento del proceso de atención.

El sistema también contemplará la posibilidad de gestionar citas destinadas a
atención virtual cuando este tipo de atención se encuentre disponible.

## Actores

- Paciente.
- Médico.
- Personal de admisión o recepción.
- Administrador del sistema.

## Canales

- Aplicación web.
- Acceso mediante navegador web desde computadoras.
- Acceso mediante navegador web desde tabletas y teléfonos móviles.

## Procesos principales

- Registro y gestión de pacientes.
- Registro y gestión de médicos.
- Gestión de especialidades médicas.
- Definición de horarios disponibles para atención.
- Consulta de médicos y especialidades.
- Consulta de horarios disponibles.
- Reserva de citas médicas.
- Reprogramación de citas.
- Cancelación de citas.
- Consulta de citas programadas.
- Gestión del estado de las citas.
- Consulta de la agenda de atención de los médicos.
- Registro de la finalización de una cita.
- Consulta del historial de citas del paciente.
- Gestión de citas para atención virtual cuando corresponda.

## Objetivo del análisis

Definir los requerimientos funcionales y no funcionales necesarios para un Sistema
Web de Gestión de Citas y Atención Virtual para el Hospital Boliviano Español.

Posteriormente, los requerimientos serán sometidos a una validación inicial mediante
un agente especializado en análisis de requerimientos, con el propósito de identificar
posibles ambigüedades, contradicciones, duplicidades, requisitos incompletos,
requisitos no verificables, inconsistencias y posibles omisiones.
