# Fuentes de imágenes — Landing Hospital Boliviano Español

## Estado

CP-LAND-04

## Decisión visual

Para la primera versión funcional de la Landing no se utilizarán
fotografías externas.

La interfaz utilizará:

- elementos gráficos creados mediante CSS;
- formas decorativas;
- iconografía simple;
- avatares neutros para médicos sin fotografía institucional;
- elementos tipográficos relacionados con salud.

## Justificación

Esta decisión evita:

- atribuir fotografías genéricas a médicos reales;
- presentar instalaciones externas como si fueran del Hospital;
- utilizar imágenes con licencia no verificada;
- incorporar recursos innecesarios antes de validar la funcionalidad.

## Política

Si posteriormente se incorpora una fotografía externa deberá registrarse:

- descripción;
- URL;
- página de origen;
- fuente;
- autor;
- licencia o condición de uso;
- fecha de verificación;
- sección donde se utiliza.

## Resultado

En la versión actual:

- imágenes externas utilizadas: 0;
- imágenes generadas con IA: 0;
- fotografías de médicos reales: 0;
- recursos con procedencia desconocida: 0.

CP-LAND-04 cumple la política de imágenes definida para el proyecto.
