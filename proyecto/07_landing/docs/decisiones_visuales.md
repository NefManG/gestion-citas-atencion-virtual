# Decisiones visuales — Hospital Boliviano Español

## Checkpoint

CP-LAND-05 — Sistema visual

## Dirección visual

La Landing utilizará una apariencia:

- profesional;
- sanitaria;
- moderna;
- limpia;
- accesible;
- institucional;
- con espacios amplios y buena jerarquía visual.

## Paleta

Color primario:
Azul hospitalario oscuro.

Color secundario:
Turquesa médico.

Fondos:
Blanco y gris muy claro.

Estados positivos:
Verde moderado.

Texto:
Gris azulado oscuro.

## Tipografía

Se utilizará una pila de fuentes del sistema para evitar
dependencias externas y mejorar performance.

## Componentes principales

- botones primarios;
- botones secundarios;
- badges;
- cards;
- navegación;
- títulos de sección;
- contenedores;
- avatares neutros;
- indicadores visuales.

## Diseño de tarjetas

Las tarjetas utilizarán:

- fondo blanco;
- borde sutil;
- radio moderado;
- sombra ligera;
- espacios amplios;
- jerarquía clara.

## Accesibilidad

Se priorizará:

- contraste;
- focus visible;
- tamaño legible;
- targets táctiles;
- no depender únicamente del color.

## Responsive

La interfaz deberá adaptarse desde móvil hasta escritorio.

## Decisión

Sistema visual aprobado como base para la construcción
de Header, Hero, Especialidades, Médicos y demás secciones.
